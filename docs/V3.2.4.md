# V3.2.4 — ouverture Vinted et dashboard

21 novembre 2026. Le choix entre site et application ne dépend pas du fait que Vinted soit déjà lancée ou fermée. iOS et le navigateur peuvent mémoriser des préférences de liens différentes sur les deux téléphones. Les réglages exacts de ces appareils n’ont pas été inspectés.

## Bouton de préparation

Le bouton principal utilise maintenant **GM_openInTab(url, {active:true, insert:true})** avec un nouveau grant. Dans [Violentmonkey 2.29.1](https://github.com/violentmonkey/violentmonkey/blob/v2.29.1/src/background/utils/tabs.js), cette API appelle browser.tabs.create : la demande passe par l’extension au lieu d’un clic sur un lien HTTPS. [Documentation de l’API](https://violentmonkey.github.io/api/gm/#gm_openintab). Cela ne prouve pas que toutes les versions d’Orion iOS gèrent cette API correctement.

Un handle d’onglet ne constitue pas une confirmation. Le module Vinted émet une réponse GM uniquement après lecture du bon transfert et reconnaissance du formulaire. La réponse est isolée par nonce et distingue ready, complete, partial et error. Le catalogue attend 12 secondes, puis propose un secours sans ouvrir un autre onglet tout seul. Un retour de visibilité/pageshow relit les réponses tardives. « Complete » signifie que les tentatives DOM ont abouti selon les contrôles existants ; il faut toujours vérifier miniatures natives, téléversement et attributs supplémentaires. Aucune publication ou sauvegarde distante.

Le secours **Abrir con Orion** utilise le schéma officiel [orion://open-url?url=…](https://help.kagi.com/orion/misc/technical.html), avec l’URL Vinted et son fragment encodés ensemble. Il demande explicitement Orion ; son comportement réel après traitement des liens universels doit être confirmé sur les deux iPhone. Si Orion propose encore l’app, choisir Never/Nunca. La [réponse de l’équipe Orion](https://orionfeedback.org/d/14721-open-links-in-prompt-suggests-apps-that-arent-installed/1) indique que ce choix est mémorisé.

Aucune ouverture répétée automatique. Le bouton principal se désactive après demande ; les marqueurs de tentative photo par nonce, le verrou navigateur et le contrôle historique sont conservés. La confirmation ne contient ni photos ni texte produit. Les marqueurs peuvent rester dans le stockage local de l’extension après expiration du transfert.

Un nouvel onglet peut recevoir un cache GM encore ancien : lecture retentée jusqu’à environ une seconde, puis erreur explicite. Si la connexion retire le fragment, **aucune fiche n’est injectée automatiquement** dans une page ouverte manuellement. Ouvrir le bouton compact Orion puis Rellenar una sola vez permet une reprise explicite du produit indiqué. Les photos déjà tentées restent protégées ; une nouvelle tentative photo exige un nouveau transfert.

## Arriver directement au dashboard

Dans le catalogue, **Acceso directo en Orion** propose deux parcours sur l’iPhone, en gardant https://example.com/ et son profil normal :

1. **Icône dédiée** : copier le lien Orion du dashboard ; dans Raccourcis/Atajos, action URL avec ce lien, puis Ouvrir les URL/Abrir URL. Nommer Orion Express et ajouter à l’écran d’accueil. Cette icône ouvre Orion à l’adresse du catalogue ; aucune application web séparée n’est créée. [Apple : schémas d’app dans Raccourcis](https://support.apple.com/en-mide/guide/shortcuts/apd68802640c/ios), [ajout de l’icône](https://support.apple.com/en-mide/guide/shortcuts/apd735880972/ios).
2. **Page d’accueil Orion** : définir Homepage sur https://example.com/, New Tabs Open With sur Homepage. Pour un nouveau départ à l’ouverture d’Orion, Start Orion With → New Tab existe, mais **ce mode ferme les onglets de la session précédente**. Préférer le raccourci pour les conserver. Les libellés peuvent varier par version/langue. [Ajout officiel Homepage iOS](https://cdn.kagi.com/updates/changelog-mobile-1.1.2.html), [comportement de démarrage confirmé par Orion](https://orionfeedback.org/d/13313-orion-ios-always-closes-all-tabs-after-a-few-hours).

Le userscript ne peut pas imposer ces préférences natives à distance. Une configuration unique sur chaque téléphone reste nécessaire. Le titre de page et les métadonnées de nom sont Orion Express pour identifier le favori. Pas de manifest, service worker, mode standalone ou migration : les extensions et les données restent dans Orion normal.

## Validation

- Tests contrôlés WebKit et Chromium : demande exacte GM_openInTab simulée et transfert complet entre deux vrais contextes de page, conservant texte et octets/ordre photo ; confirmation par nonce, aucune seconde ouverture sans réponse ; reprise explicite sans fragment, pas de publication ; erreurs et contrôles antérieurs conservés.
- Tests d’accès dashboard : espagnol par défaut, français, URL et schéma exacts, copie avec/sans permission, retour catalogue, produits V1 et photos inchangés.
- Tests Node : destinations admises/rejetées, encodage du fragment, API absente, ACK isolés, états/temps/contenus malformés et autres non-régressions.
- **NON VALIDÉ sur appareil réel** pour cette version : neutralisation effective de l’app Vinted par l’API d’extension ou le schéma Orion, installation du raccourci, choix d’accueil des deux iPhone et droits réels du nouveau grant. Les stubs GM ne constituent pas un test de Violentmonkey réel.

`src/core.js`, l’adaptateur de catégorie/colis, le module d’état et les fonctions de transfert de fichiers restent inchangés. Même identité Violentmonkey, URL de mise à jour main et anciennes versions conservées.
